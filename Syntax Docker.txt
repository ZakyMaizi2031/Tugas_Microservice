===========================================================
Langkahnya

1.Masuk setiap servicenya kecuali RabbitMQ

2.mvn clean package -DskipTests(tiap service)

3.docker build -t perpus/eureka-server:1.0 ./eureka-server
  docker build -t perpus/api-gateway:1.0 ./api_gateway
  docker build -t perpus/buku-service:1.0 ./buku
  docker build -t perpus/anggota-service:1.0 ./anggota
  docker build -t perpus/peminjaman-service:1.0 ./peminjaman
  docker build -t perpus/pengembalian-service:1.0 ./pengembalian_service

4.masuk ke manifest, kubectl apply -f 00-namespace.yaml, kubectl apply -f 06-secrets.yaml, kubectl apply -f 01-infrastructure.yaml, cek pods(kubectl get pods -n perpustakaan-ns), kubectl apply -f 02-eureka.yaml, kubectl apply -f 03-apps.yaml, kubectl apply -f 04-gateway.yaml

5. Coba dipostman

6. masuk ke directory monitoring-logging, masuk ke diredtory elk, running "docker compose up"

7. masuk ke directory monitoring -logging, masuk ke Grafana, running "docker compose up"

8. masuk ke directory monitoring -logging, masuk ke prometheus, running "docker compose up"

9. akses Kibana:
	localhost:5601

10.grafana:
	localhost:3000

11. Prometheus
	localhost:30081/actuator/prometheus
